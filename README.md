# B1-1 시스테 관제 자동화 스크립트 개발

## 4-Part 구조

| Part | 항목 | 성격 |
|---|---|---|
| Part 1 | B1-1 평가 제출편 | 필수 구현, 보너스, 평가문항 대응, evidence, GitHub 제출 |
| Part 2 | 실무 운영 확장편 | Docker, Cloud, 시스템 관제 엔지니어 운영 고도화 |
| Part 3 | 보안 실무·기준 매핑편 | Linux/Docker/개발/스크립트/GitHub/크라우드 보안, 국내·국제 기준 매핑 |
| Part 4 | 반복 훈련편 | 선수지식, 명령어 반복, 장애 재현, GitHub Flow 훈련, 구술 훈련, 모의평가 |

## 진행 원칙

1. Part 1을 먼저 완료한다.
2. 각 장은 브랜치를 만들어 작업한다.
3. 명령어 실행 결과는 evidence/에 저장한다.
4. PR로 main에 병합한다.
5. Part 2~4는 포트폴리오 확장으로 진행한다.
