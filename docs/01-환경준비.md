# 환경 준비

## 이 단계의 목표

macOS 프로젝트 폴더와 OrbStack Ubuntu 실습 환경을 분리해서 확인한다.

## 왜 이 작업을 하는가?

SSH, 방화벽, 사용자, cron, `/var/log` 권한은 Linux 실습 환경에서 수행해야 한다. macOS는 작업 호스트로 사용하고, 시스템 변경 실습은 OrbStack Ubuntu에서 진행한다.

## 사전 확인

macOS에서 프로젝트 폴더로 이동한다.

```bash
cd ~/codyssey/codyssey-b1-1-system-monitor
pwd
ls -la
git status
```

OrbStack Ubuntu에서 확인한다.

```bash
cat /etc/os-release
uname -a
uname -m
whoami
id
hostname
```

## 실행 명령어

필요 패키지를 Ubuntu에서 확인한다.

```bash
command -v unzip
command -v ss
command -v ufw
command -v logrotate
command -v crontab
```

없으면 Ubuntu에서 설치한다.

```bash
sudo apt update
sudo apt install -y unzip iproute2 ufw logrotate cron acl
```

## 명령어 설명

- `unzip`: 제공 앱 압축 해제에 사용한다.
- `ss`: 포트 LISTEN 확인에 사용한다.
- `ufw`: 방화벽 설정에 사용한다.
- `logrotate`: monitor.log 용량 관리에 사용한다.
- `cron`: monitor.sh 매분 실행에 사용한다.
- `acl`: `getfacl` 확인 명령에 사용한다.

## 기대 결과

Ubuntu 22.04 또는 24.04에서 필요한 명령이 준비된다.

## 결과 확인 명령어

```bash
cat /etc/os-release
uname -m
command -v unzip ss ufw logrotate crontab getfacl
```

## 자주 발생하는 오류

- `ufw: command not found`: `sudo apt install -y ufw`
- `getfacl: command not found`: `sudo apt install -y acl`
- `crontab: command not found`: `sudo apt install -y cron`
