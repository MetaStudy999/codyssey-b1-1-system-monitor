## 이 단계의 목표

macOS 프로젝트 폴더와 OrbStack Ubuntu 실습 환경을 분리해서 확인한다.

## 왜 이 작업을 하는가?

SSH, 방화벽, 사용자, cron, `/var/log` 권한은 Linux 실습 환경에서 수행해야 한다. macOS는 작업 호스트로 사용하고, 시스템 변경 실습은 OrbStack Ubuntu에서 진행한다.

## OrbStack Ubuntu Machine/VM 생성

아직 Ubuntu 실습 환경이 없다면 macOS 터미널에서 `orb` 명령으로 Ubuntu Machine을 먼저 만든다. 이 문서에서는 OrbStack의 Linux Machine을 실습용 Ubuntu VM으로 사용한다.

macOS에서 OrbStack CLI가 준비되어 있는지 확인한다.

```bash
orb version

Version: 2.0.5 (2000500)
Commit: cfe47627f138ffd822c958553b0a93eaf2692c71 (v2.0.5)

---

orb status

Running
```

## Ubuntu 버전 선택 기준

이 미션의 기본 실습 환경은 Ubuntu 22.04 LTS이다. 제공 앱 실행 중 `GLIBC_2.38 not found`처럼 라이브러리 호환 문제가 발생하면 Ubuntu 24.04 LTS에서 먼저 다시 검증한다.

Ubuntu 25.04는 이미 OrbStack VM이 준비되어 있을 때 보조 검증용으로만 사용한다. 25.04는 LTS가 아니고 2026-05-28 기준 EOL 상태이므로 장기 실습과 최종 제출 증빙은 가능하면 22.04 또는 24.04에서 남긴다.

선택 기준:

```text
1순위: Ubuntu 22.04 LTS, Jammy, 기본 실습 환경
2순위: Ubuntu 24.04 LTS, Noble, GLIBC_2.38 이상 또는 패키지 호환 문제 대응
3순위: Ubuntu 25.04, Plucky, 이미 생성된 VM에서 보조 호환성 확인
```

새로 생성해야 하는 경우에는 Plucky 코드명을 사용한다. 단, 25.04는 LTS가 아니고 EOL 상태이므로 패키지 저장소나 보안 업데이트 상태가 LTS보다 불리할 수 있다.

```bash
orb create ubuntu:plucky codyssey-b1-1-ubuntu25

Creating codyssey-b1-1-ubuntu24

orb -m codyssey-b1-1-ubuntu25
```

GUI로 생성해야 하는 경우에는 macOS에서 OrbStack 앱을 열고 아래 순서로 만든다.

1. OrbStack 앱을 실행한다.
2. Linux 또는 Machines 화면에서 새 Machine 생성을 선택한다.
3. Distribution은 Ubuntu를 선택한다.
4. Version은 Ubuntu 22.04 LTS를 우선 선택한다. GLIBC 또는 패키지 호환 문제가 있으면 Ubuntu 24.04 LTS를 선택한다. 이미 Ubuntu 25.04 Machine이 있다면 보조 검증용으로만 사용한다.
5. 이름은 예를 들어 `codyssey-b1-1-ubuntu24`처럼 미션을 구분할 수 있게 지정한다.
6. Machine을 생성한 뒤 Start 또는 Open Terminal로 Ubuntu 터미널에 접속한다.
7. 아래 사전 확인 명령으로 Ubuntu 버전과 사용자 정보를 확인한다.

## 실행 명령어

필요 패키지를 Ubuntu에서 확인한다.


```bash
command -v unzip
command -v ss
command -v sshd
command -v ufw
command -v logrotate
command -v crontab
command -v getfacl
command -v curl
command -v file
command -v nano
```

없으면 Ubuntu에서 설치한다.

```bash
sudo apt update
sudo apt install -y openssh-server unzip iproute2 ufw logrotate cron acl curl file nano
```

## 명령어 설명

- `unzip`: 제공 앱 압축 해제에 사용한다.
- `ss`: 포트 LISTEN 확인에 사용한다.
- `openssh-server`: `sshd_config`, `sshd -t`, SSH 포트 변경 검증에 필요하다.
- `ufw`: 방화벽 설정에 사용한다.
- `logrotate`: monitor.log 용량 관리에 사용한다.
- `cron`: monitor.sh 매분 실행에 사용한다.
- `acl`: `getfacl` 확인 명령에 사용한다.
- `curl`: agent-app HTTP 응답 확인에 사용한다.
- `file`: 배치한 agent-app 실행 파일의 아키텍처 확인에 사용한다.
- `nano`: SSH 설정 파일을 수동 편집할 때 사용한다.

## 자주 발생하는 오류

- `ufw: command not found`: `sudo apt install -y ufw`
- `sshd: command not found`: `sudo apt install -y openssh-server`
- `getfacl: command not found`: `sudo apt install -y acl`
- `crontab: command not found`: `sudo apt install -y cron`
- `curl: command not found`: `sudo apt install -y curl`
- `file: command not found`: `sudo apt install -y file`
- `nano: command not found`: `sudo apt install -y nano`
