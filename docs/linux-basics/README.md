# Linux 기초 참고 문서

## 이 폴더의 목적

B1-1 미션을 진행하면서 나오는 Linux 명령어, 용어, 개념을 따로 정리한다.

미션 문서는 "무엇을 실행할지"를 중심으로 보고, 이 폴더는 "그 명령과 개념이 무슨 뜻인지"를 복습할 때 사용한다.

## 문서 구성

| 문서 | 내용 |
|---|---|
| `01-commands.md` | B1-1에서 사용하는 Linux 명령어 설명 |
| `02-terms.md` | 사용자, 그룹, 권한, 프로세스, 포트 같은 용어 정리 |
| `03-concepts.md` | 최소 권한, 멱등성, cron 환경, 로그 관리 같은 운영 개념 정리 |
| `shell-training/README.md` | 리눅스 쉘 프로그램 따라하기 트레이닝 교재 |

## 사용하는 방법

1. 미션 문서에서 모르는 명령어가 나오면 `01-commands.md`를 확인한다.
2. 명령어 설명 중 모르는 단어가 나오면 `02-terms.md`를 확인한다.
3. 왜 그렇게 구성하는지 설명이 필요하면 `03-concepts.md`를 확인한다.
4. Bash 스크립트를 직접 따라 만들며 연습하려면 `shell-training/README.md`부터 진행한다.

## 작성 원칙

- 명령어는 실제 미션에서 사용하는 예시와 함께 정리한다.
- 용어는 외우기보다 "어디에 쓰이는지"를 중심으로 설명한다.
- 개념은 동료 평가에서 말로 설명할 수 있는 수준으로 정리한다.
- 새로운 명령어를 사용하면 이 폴더에도 함께 추가한다.
