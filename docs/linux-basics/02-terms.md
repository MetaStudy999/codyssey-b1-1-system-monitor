# Linux 용어 정리

## 사용자와 권한

### 사용자

Linux에서 명령을 실행하고 파일을 소유하는 주체다.

B1-1에서는 다음 사용자를 만든다.

- `agent-admin`: 앱 실행과 운영 담당
- `agent-dev`: 스크립트와 설정 관리 담당
- `agent-test`: 테스트 담당

### 그룹

여러 사용자에게 같은 권한을 주기 위한 단위다.

B1-1에서는 다음 그룹을 사용한다.

- `agent-common`: 세 계정이 함께 접근하는 공유 그룹
- `agent-core`: 운영 핵심 파일에 접근하는 제한 그룹

### UID

User ID의 약자다. Linux가 사용자를 내부적으로 구분하는 숫자다.

### GID

Group ID의 약자다. Linux가 그룹을 내부적으로 구분하는 숫자다.

### 주 그룹

사용자가 기본으로 속하는 그룹이다. 파일을 만들 때 기본 그룹으로 사용될 수 있다.

### 보조 그룹

사용자가 추가로 속하는 그룹이다. `usermod -aG`로 추가한다.

### root

Linux의 최고 관리자 계정이다. 모든 파일과 설정에 접근할 수 있으므로 앱을 root로 실행하지 않는 것이 원칙이다.

### sudo

일반 사용자가 일시적으로 관리자 권한으로 명령을 실행하게 해주는 도구다.

## 파일과 디렉터리

### 홈 디렉터리

사용자별 기본 작업 공간이다.

예:

```text
/home/agent-admin
```

### 소유자

파일이나 디렉터리를 소유한 사용자다.

### 소유 그룹

파일이나 디렉터리에 연결된 그룹이다. 같은 그룹에 속한 사용자에게 권한을 줄 수 있다.

### others

소유자도 아니고 소유 그룹에도 속하지 않는 나머지 사용자다.

### 권한

파일이나 디렉터리에 대해 읽기, 쓰기, 실행을 허용할지 정하는 규칙이다.

- `r`: read, 읽기
- `w`: write, 쓰기
- `x`: execute, 실행 또는 디렉터리 진입

### ACL

Access Control List의 약자다. 기본 소유자/그룹/others 권한보다 더 세밀하게 접근 권한을 줄 때 사용한다.

## 프로세스와 네트워크

### 프로세스

실행 중인 프로그램이다. 앱이 실행되면 하나 이상의 프로세스가 생긴다.

### PID

Process ID의 약자다. Linux가 프로세스를 구분하는 숫자다.

### 포트

네트워크 프로그램이 요청을 받는 번호다. B1-1 앱은 `15034` 포트를 사용한다.

### LISTEN

프로그램이 특정 포트에서 요청을 받을 준비가 된 상태다.

`ss -tulnp`에서 `LISTEN`이 보이면 해당 포트가 열려 있다는 뜻이다.

### localhost

현재 자기 자신을 가리키는 주소다.

```text
127.0.0.1
```

### 방화벽

서버로 들어오는 네트워크 접근을 허용하거나 차단하는 보안 장치다.

B1-1에서는 SSH용 `20022/tcp`, 앱용 `15034/tcp`만 허용한다.

## 로그와 자동화

### 로그

시스템이나 앱에서 발생한 일을 시간순으로 기록한 파일이다.

예:

```text
/var/log/agent-app/monitor.log
```

### stdout

표준 출력이다. 명령이 정상 결과를 출력하는 통로다.

### stderr

표준 에러다. 명령이 오류 메시지를 출력하는 통로다.

### exit code

명령이 끝난 뒤 성공 또는 실패를 나타내는 숫자다.

- `0`: 성공
- `1` 이상: 실패

### cron

정해진 시간마다 명령을 자동 실행하는 Linux 스케줄러다.

### crontab

cron에 등록할 작업 목록이다.

예:

```text
* * * * * /home/agent-admin/agent-app/bin/monitor.sh
```

### logrotate

로그 파일이 너무 커지지 않도록 회전, 압축, 보관 개수를 관리하는 도구다.
