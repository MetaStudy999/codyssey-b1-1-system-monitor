# 보너스 로그 아카이브

## 이 단계의 목표

7일 이상 지난 `/var/log/agent-app/*.log`를 압축하고, `/var/log/monitor/agent-app/archive/`로 이동하며, 30일 이상 지난 `.gz` 아카이브를 삭제한다.

## 왜 이 작업을 하는가?

용량 기반 rotate와 별도로 시간 기반 보존 정책을 두면 오래된 로그를 압축해 보관하고, 너무 오래된 아카이브를 자동 삭제할 수 있다.

## 사전 확인

```bash
ls -ld /var/log/agent-app
find /var/log/agent-app -maxdepth 1 -type f -name "*.log" -ls
```

## 실행 명령어

문법 검사:

```bash
bash -n scripts/archive-old-logs.sh
```

실행:

```bash
sudo bash scripts/archive-old-logs.sh
```

## 명령어 설명

- `find "$LOG_DIR" -name '*.log' -mtime +6`: 7일 이상 지난 로그를 찾는다.
- `gzip -c`: 원본을 읽어 압축 파일을 만든다.
- `mv`: 압축 파일을 archive 디렉터리로 이동한다.
- `find "$ARCHIVE_DIR" -name '*.gz' -mtime +29`: 30일 이상 지난 압축 파일을 찾는다.

## 기대 결과

```text
[INFO] Archive directory checked: /var/log/monitor/agent-app/archive
[INFO] No old log files found for compression
[INFO] No old archive files found for deletion
[INFO] Archive cleanup completed
```

오래된 파일이 있으면 압축/이동/삭제 메시지가 출력된다.

## 결과 확인 명령어

```bash
find /var/log/monitor/agent-app/archive -type f -name "*.gz" -ls
```

## 자주 발생하는 오류

- archive 디렉터리 생성 실패: `/var/log/monitor`에 대한 root 권한이 필요하다.
- gzip 실패: 원본 로그 읽기 권한과 디스크 여유 공간을 확인한다.
- 대상 파일 없음: 정상 상황이며 INFO로 종료한다.
