# 계정과 그룹 생성

## 이 단계의 목표

`agent-admin`, `agent-dev`, `agent-test` 계정과 `agent-common`, `agent-core` 그룹을 만든다.

## 왜 이 작업을 하는가?

운영자는 앱을 실행하고, 개발자는 스크립트를 관리하며, 테스트 계정은 공유 업로드 영역만 접근하게 만든다. 이것이 역할 기반 접근 제어의 기본이다.

## 사전 확인

Ubuntu에서 실행한다.

```bash
id agent-admin
id agent-dev
id agent-test
getent group agent-common
getent group agent-core
```

아직 생성 전이면 일부 명령은 실패하는 것이 정상이다.

## 실행 명령어

```bash
sudo bash scripts/setup-users.sh
```

## 명령어 설명

- `agent-common`: admin/dev/test가 모두 들어가는 공유 그룹이다.
- `agent-core`: admin/dev만 들어가는 핵심 운영 그룹이다.
- 스크립트는 이미 존재하는 사용자와 그룹은 건너뛰므로 여러 번 실행해도 안전하다.

## 기대 결과

```text
agent-admin, agent-dev, agent-test 계정 생성
agent-common, agent-core 그룹 생성
agent-common: 세 계정 모두 포함
agent-core: agent-admin, agent-dev 포함
```

## 결과 확인 명령어

```bash
id agent-admin
id agent-dev
id agent-test
getent group agent-common
getent group agent-core
```

## 자주 발생하는 오류

- `Permission denied`: `sudo`로 실행해야 한다.
- 그룹에 추가했는데 `id`에 바로 안 보임: 로그인 세션을 다시 열어야 할 수 있다.
