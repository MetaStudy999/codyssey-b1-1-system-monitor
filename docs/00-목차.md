# B1-1 시스템 관제 자동화 목차

## 이 단계의 목표

B1-1 미션 전체 흐름을 한눈에 확인하고, 어떤 명령을 macOS에서 실행하고 어떤 명령을 OrbStack Ubuntu에서 실행해야 하는지 구분한다.

## 왜 이 작업을 하는가?

이 미션은 단순히 Bash 파일 하나를 만드는 과제가 아니다. SSH, 방화벽, 사용자/그룹, 디렉터리 권한, 앱 실행, 관제 로그, cron, logrotate까지 운영 흐름 전체를 증빙해야 한다.

## 명령어 설명

- macOS: Git, 문서 편집, ZIP 파일 이동, 제출 준비를 담당한다.
- OrbStack Ubuntu: 사용자/그룹, 권한, SSH, UFW, cron, 앱 실행 검증을 담당한다.
- OrbStack Ubuntu Machine/VM: `orb create` 명령으로 Ubuntu 22.04 LTS를 우선 생성하고, GLIBC 호환 문제가 있으면 Ubuntu 24.04 LTS를 먼저 검토한다. Ubuntu 25.04는 이미 준비된 VM이 있을 때 보조 검증용으로만 사용한다.
- Docker: 이 미션에서는 보조 수단이다. 사용자/cron/systemd 실습은 OrbStack Ubuntu Machine이 더 적합하다.

## 자주 발생하는 오류

- macOS에서 `useradd`, `ufw`, `systemctl`을 실행하려고 하는 경우: OrbStack Ubuntu에서 실행해야 한다.
- ZIP을 먼저 무작정 풀고 파일명을 헷갈리는 경우: `unzip -l agent-app.zip`으로 내부 목록을 먼저 확인한다.
