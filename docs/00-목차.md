# B1-1 시스템 관제 자동화 목차

## 이 단계의 목표

B1-1 미션 전체 흐름을 한눈에 확인하고, 어떤 명령을 macOS에서 실행하고 어떤 명령을 OrbStack Ubuntu에서 실행해야 하는지 구분한다.

## 왜 이 작업을 하는가?

이 미션은 단순히 Bash 파일 하나를 만드는 과제가 아니다. SSH, 방화벽, 사용자/그룹, 디렉터리 권한, 앱 실행, 관제 로그, cron, logrotate까지 운영 흐름 전체를 증빙해야 한다.

## 사전 확인

아래는 실제로 입력하는 명령과 참고용 출력 예시를 구분해서 정리한 것이다.

### macOS에서 실행하는 명령

macOS 프로젝트 폴더에서 현재 위치와 Git 상태를 확인한다.

```bash
cd ~/codyssey/codyssey-b1-1-system-monitor
pwd
ls -la
git status
```

OrbStack Ubuntu Machine/VM 목록을 확인하고, Ubuntu 22.04 Machine에 접속한다.

```bash
orb list
orb -m codyssey-b1-1-ubuntu22
```

OrbStack Ubuntu Machine/VM이 아직 없으면 `docs/01-환경준비.md`에서 `orb create` 명령으로 먼저 생성한다.

### Ubuntu 접속 후 실행하는 명령

`orb -m codyssey-b1-1-ubuntu22` 실행 후 프롬프트가 Ubuntu Machine으로 바뀌면 다음을 확인한다.

```bash
cat /etc/os-release
uname -m
whoami
id
id | sed 's/ /\n/g; s/,/\n /g'
```

## 명령어 설명

- macOS: Git, 문서 편집, ZIP 파일 이동, 제출 준비를 담당한다.
- OrbStack Ubuntu: 사용자/그룹, 권한, SSH, UFW, cron, 앱 실행 검증을 담당한다.
- OrbStack Ubuntu Machine/VM: `orb create` 명령으로 Ubuntu 22.04 LTS를 우선 생성하고, GLIBC 호환 문제가 있으면 Ubuntu 24.04 LTS를 먼저 검토하고, Ubuntu 25.04는 이미 준비된 VM이 있을 때 보조 검증용으로만 사용한다.
- Docker: 이 미션에서는 보조 수단이다. 사용자/cron/systemd 실습은 OrbStack Ubuntu Machine이 더 적합하다.
- `cd ~/codyssey/codyssey-b1-1-system-monitor`: macOS에서 미션 프로젝트 폴더로 이동한다.
- `pwd`: 현재 작업 위치가 올바른지 확인한다.
- `ls -la`: 현재 폴더의 파일과 디렉터리 목록을 확인한다.
- `git status`: Git 변경 상태를 확인한다.
- `orb list`: macOS에서 OrbStack Machine/VM 목록과 실행 상태를 확인한다.
- `orb -m codyssey-b1-1-ubuntu22`: macOS에서 Ubuntu 22.04 Machine으로 접속한다.
- `cat /etc/os-release`: Ubuntu 버전 정보를 확인한다.
- `uname -m`: CPU 아키텍처가 `x86_64`인지 확인한다.
- `whoami`: 현재 Ubuntu 로그인 사용자를 확인한다.
- `id`: 현재 사용자의 UID, GID, 소속 그룹을 확인한다.

## 자주 발생하는 오류

- macOS에서 `useradd`, `ufw`, `systemctl`을 실행하려고 하는 경우: OrbStack Ubuntu에서 실행해야 한다.
- ZIP을 먼저 무작정 풀고 파일명을 헷갈리는 경우: `unzip -l agent-app.zip`으로 내부 목록을 먼저 확인한다.
