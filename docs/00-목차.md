# B1-1 시스템 관제 자동화 목차

## 이 단계의 목표

B1-1 미션 전체 흐름을 한눈에 확인하고, 어떤 명령을 macOS에서 실행하고 어떤 명령을 `codyssey-b1-1-ubuntu24`에서 실행해야 하는지 구분한다.

## 왜 이 작업을 하는가?

이 미션은 단순히 Bash 파일 하나를 만드는 과제가 아니다. SSH, 방화벽, 사용자/그룹, 디렉터리 권한, 앱 실행, 관제 로그, cron, logrotate까지 운영 흐름 전체를 증빙해야 한다.

## 사전 확인

아래는 실제로 입력하는 명령과 참고용 출력 예시를 구분해서 정리한 것이다.

### macOS에서 실행하는 명령

macOS 프로젝트 폴더에서 현재 위치와 Git 상태를 확인한다.

```bash
cd ~/codyssey/codyssey-b1-1-system-monitor
pwd
ls -la
git status
```

OrbStack Ubuntu 24.04 VM 목록을 확인하고 `codyssey-b1-1-ubuntu24`에 접속한다.

```bash
orb list
orb -m codyssey-b1-1-ubuntu24
```

`codyssey-b1-1-ubuntu24` VM이 아직 없으면 `docs/01-환경준비.md`에서 `orb create` 명령으로 먼저 생성한다.

### Ubuntu 접속 후 실행하는 명령

`orb -m codyssey-b1-1-ubuntu24` 실행 후 프롬프트가 Ubuntu 24.04 VM으로 바뀌면 다음을 확인한다.

```bash
cat /etc/os-release
uname -m
whoami
id
id | sed 's/ /\n/g; s/,/\n /g'
```

`id | sed 's/ /\n/g; s/,/\n /g'`는 `id` 명령의 출력에서 공백과 쉼표를 줄바꿈으로 바꿔 UID, GID, 소속 그룹을 한 줄씩 보기 쉽게 정리한다.

기본 문법 형식은 다음과 같다.

```text
명령1 | 명령2
sed 's/찾을_문자/바꿀_문자/옵션'
sed 's/찾을_문자/바꿀_문자/옵션; s/찾을_문자/바꿀_문자/옵션'
```

이 명령에 적용하면 다음과 같이 읽을 수 있다.

- `id | sed ...`: `id` 출력 결과를 `sed`가 받아서 가공한다.
- `s/ /\n/g`: 찾을 문자는 공백이고, 바꿀 문자는 줄바꿈이며, `g` 옵션으로 모든 공백에 적용한다.
- `s/,/\n /g`: 찾을 문자는 쉼표이고, 바꿀 문자는 줄바꿈과 한 칸 공백이며, `g` 옵션으로 모든 쉼표에 적용한다.

구성 요소별 의미는 다음과 같다.

- `id`: 현재 사용자의 UID, GID, 소속 그룹 정보를 출력한다.
- `|`: 왼쪽 명령의 출력 결과를 오른쪽 명령의 입력으로 넘기는 파이프다.
- `sed`: 입력받은 텍스트를 규칙에 따라 바꾸는 텍스트 처리 명령이다.
- `'s/ /\n/g; s/,/\n /g'`: `sed`에 전달하는 두 개의 치환 규칙이다. 작은따옴표로 감싸서 셸이 공백과 특수문자를 먼저 해석하지 않게 한다.
- `s/ /\n/g`: 공백 문자를 줄바꿈으로 바꾼다. `s`는 substitute, 즉 치환을 뜻하고, 마지막 `g`는 한 줄 안의 모든 공백에 적용한다는 뜻이다.
- `;`: `sed` 규칙을 여러 개 이어서 실행할 때 사용하는 구분자다.
- `s/,/\n /g`: 쉼표를 줄바꿈과 한 칸 공백으로 바꾼다. 그래서 `groups=...,...,...`처럼 이어진 그룹 목록이 줄마다 들여쓰기되어 보인다.

## 명령어 설명

- macOS: Git, 문서 편집, ZIP 파일 이동, 제출 준비를 담당한다.
- `codyssey-b1-1-ubuntu24`: 사용자/그룹, 권한, SSH, UFW, cron, 앱 실행 검증을 담당한다.
- OrbStack Ubuntu 24.04 VM: `orb create ubuntu:noble codyssey-b1-1-ubuntu24` 명령으로 생성하고 이 VM에서 모든 Linux 실습 증빙을 남긴다.
- Docker: 이 미션에서는 보조 수단이다. 사용자/cron/systemd 실습은 `codyssey-b1-1-ubuntu24`가 더 적합하다.
- `cd ~/codyssey/codyssey-b1-1-system-monitor`: macOS에서 미션 프로젝트 폴더로 이동한다.
- `pwd`: 현재 작업 위치가 올바른지 확인한다.
- `ls -la`: 현재 폴더의 파일과 디렉터리 목록을 확인한다.
- `git status`: Git 변경 상태를 확인한다.
- `orb list`: macOS에서 OrbStack Machine/VM 목록과 실행 상태를 확인한다.
- `orb -m codyssey-b1-1-ubuntu24`: macOS에서 Ubuntu 24.04 VM으로 접속한다.
- `cat /etc/os-release`: Ubuntu 버전 정보를 확인한다.
- `uname -m`: CPU 아키텍처가 `x86_64`인지 확인한다.
- `whoami`: 현재 Ubuntu 로그인 사용자를 확인한다.
- `id`: 현재 사용자의 UID, GID, 소속 그룹을 확인한다.

## 자주 발생하는 오류

- macOS에서 `useradd`, `ufw`, `systemctl`을 실행하려고 하는 경우: `codyssey-b1-1-ubuntu24`에서 실행해야 한다.
