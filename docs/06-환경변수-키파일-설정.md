# 환경변수와 키 파일 설정

## 이 단계의 목표

`agent-admin` 계정 기준으로 앱 실행에 필요한 환경 변수를 설정하고 키 파일을 확인한다.

## 왜 이 작업을 하는가?

앱이 디렉터리와 키 파일 위치를 안정적으로 찾게 하려면 실행 환경을 환경 변수로 고정해야 한다. cron은 환경 변수가 적으므로 스크립트 내부 기본값도 함께 둔다.

## 사전 확인

```bash
sudo -iu agent-admin
whoami
pwd
```

## 실행 명령어

`agent-admin` 계정으로 `.profile`에 추가한다.

```bash
cat >> ~/.profile <<'EOF'
export AGENT_HOME=/home/agent-admin/agent-app
export AGENT_PORT=15034
export AGENT_UPLOAD_DIR=$AGENT_HOME/upload_files
export AGENT_KEY_PATH=$AGENT_HOME/api_keys/t_secret.key
export AGENT_LOG_DIR=/var/log/agent-app
EOF

source ~/.profile
```

키 파일을 확인한다.

```bash
echo "$AGENT_HOME"
echo "$AGENT_PORT"
echo "$AGENT_UPLOAD_DIR"
echo "$AGENT_KEY_PATH"
echo "$AGENT_LOG_DIR"
cat "$AGENT_KEY_PATH"
```

## 명령어 설명

- `.profile`: 로그인 셸에서 환경 변수를 자동으로 읽는다.
- `source ~/.profile`: 현재 터미널에 즉시 반영한다.
- 키 파일 내용은 미션용 테스트 문자열인 `agent_api_key_test`다.

## 기대 결과

```text
AGENT_HOME=/home/agent-admin/agent-app
AGENT_PORT=15034
AGENT_UPLOAD_DIR=/home/agent-admin/agent-app/upload_files
AGENT_KEY_PATH=/home/agent-admin/agent-app/api_keys/t_secret.key
AGENT_LOG_DIR=/var/log/agent-app
agent_api_key_test
```

## 결과 확인 명령어

```bash
sudo -iu agent-admin env | grep '^AGENT_'
sudo -u agent-admin cat /home/agent-admin/agent-app/api_keys/t_secret.key
```

## 자주 발생하는 오류

- cron에서 환경 변수가 없음: `monitor.sh`는 기본값을 가지고 있으므로 직접 실행과 cron 모두 동작한다.
- 키 파일 접근 거부: `agent-admin`이 `agent-core`에 포함되어 있는지 확인한다.
