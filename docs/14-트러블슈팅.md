# 트러블슈팅

## 이 단계의 목표

B1-1 수행 중 자주 발생하는 문제를 빠르게 확인하고 해결한다.

## 왜 이 작업을 하는가?

운영 환경에서는 문제가 발생했을 때 원인 후보를 세우고 증거로 확인하는 능력이 중요하다.

## 사전 확인

문제가 발생하면 먼저 어느 환경인지 구분한다.

```bash
uname -a
cat /etc/os-release
whoami
pwd
```

## 실행 명령어

자세한 트러블슈팅 보고서는 `docs/troubleshooting.md`를 함께 사용한다.

```bash
less docs/troubleshooting.md
```

## 명령어 설명

- `uname -a`: OS와 커널 정보를 확인한다.
- `whoami`: 현재 실행 계정을 확인한다.
- `pwd`: 올바른 프로젝트/실습 위치인지 확인한다.

## 기대 결과

문제를 환경, 권한, 프로세스, 포트, cron, 로그, 바이너리 호환성 중 하나로 분류할 수 있다.

## 결과 확인 명령어

문제 유형별 확인 명령은 `docs/troubleshooting.md`에 정리한다.

## README에 붙여넣을 증빙

대표 문제 1~2개에 대해 증상, 원인, 해결 결과를 요약해서 붙인다.

## 자주 발생하는 오류

- root로 앱 실행 실패
- 15034 포트 미사용
- cron에서는 실패하지만 직접 실행은 성공
- monitor.log 권한 오류
- GLIBC 오류
